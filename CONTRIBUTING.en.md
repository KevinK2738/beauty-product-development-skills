# Contributing

[简体中文](CONTRIBUTING.md)

Issues, case corrections, and capability improvements are welcome. Contributions should improve a real decision, artifact, or stopping boundary. Additions that only increase length, workflow steps, or generic advice will not be accepted.

## Before submitting

- Describe the real task or failure mode addressed.
- Cite a public source, publisher, and access date for new factual claims.
- State whether the contribution is original, authorized, or an independently written summary of public facts.
- Do not submit confidential client, employer, supplier, partner, contact, or quotation data.
- Do not copy long passages from courses, reports, webpages, templates, or other skills.
- State each new rule's trigger, required evidence, and non-applicable cases.
- Update both language versions when bilingual content changes.
- Run `python3 scripts/validate_repo.py` and resolve all errors.

By submitting a contribution, you agree that it is licensed under Apache-2.0 unless the submission clearly identifies a compatible license and source.

## Pull requests

Describe the problem, change, evidence, rights status, validation case, and known limitations. Real brand names may identify public sources only and must not imply brand participation or endorsement.
