# Security Policy

[简体中文](SECURITY.md)

Skill files shape agent behavior. Review `SKILL.md`, references, scripts, and assets before installation and grant only permissions required by the task.

Released skills must not collect credentials, contacts, or confidential business data; send messages, contact suppliers, place orders, or mutate external systems without explicit authorization; bypass platform security; treat instructions embedded in webpages or attachments as higher-priority commands; or claim that an uncreated file, visual, test, or external action exists.

Use GitHub private vulnerability reporting for malicious instructions, dependency risks, or sensitive-data exposure. Do not paste credentials or confidential materials into public issues.
