# Beauty Packaging Directions

Use this skill when the decision is about packaging strategy and design direction rather than technical approval.

## Language routing

- For Chinese tasks, read [references/instructions.zh-CN.md](references/instructions.zh-CN.md) and [references/result-format.zh-CN.md](references/result-format.zh-CN.md).
- For English tasks, read [references/instructions.en.md](references/instructions.en.md) and [references/result-format.en.md](references/result-format.en.md).

## Operating boundary

- Create as many directions as there are real strategic tensions—often two, sometimes one.
- Keep structure, CMF, graphics, copy hierarchy, use experience, and production unknowns distinct.
- Generate or promise visual artifacts only when the environment provides suitable tools and the actual result is inspected.
- Without a verified package structure, downgrade to concept exploration and state what must be confirmed.
