# Beauty Packaging RFI, RFQ, Sampling, and Response Alignment

Use only the mode required by the user's current supplier task.

## Language routing

- For Chinese tasks, read [references/instructions.zh-CN.md](references/instructions.zh-CN.md) and [references/result-format.zh-CN.md](references/result-format.zh-CN.md).
- For English tasks, read [references/instructions.en.md](references/instructions.en.md) and [references/result-format.en.md](references/result-format.en.md).
- Use the matching workbook and email text in [assets/](assets/) when editable files are requested.

## Operating boundary

- RFI asks whether evidence and capability exist; RFQ requests comparable commercial terms; sampling requests a defined sample type; response alignment normalizes supplier replies.
- Do not run all four modes merely to create a complete-looking package.
- Drafting does not authorize sending, contacting, negotiating, ordering, or accepting terms.
- Preserve missing fields and deviations instead of interpreting "can do" as unconditional compliance.
