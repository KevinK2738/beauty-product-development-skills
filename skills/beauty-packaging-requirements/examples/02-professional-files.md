## 模拟输入 / Simulated inputs

- 内容物摘要：高黏度眼霜，流变曲线和颗粒信息待提供。
- 使用体验要求：希望通过按摩头直接涂抹，避免拉扯眼周。
- 商业条件：15 ml，中国电商；目标成本、首单量和装饰方案未决。
- 候选资料：一个公开真空瓶页面，未包含按摩头、阀路和剂量数据。

## 用户用法 / User prompt

“把这些文件整理成可供包材、研发和测试共同评审的包装需求书。” / “Turn these files into packaging requirements for joint packaging, R&D, and test review.”

## 预期行为 / Expected behavior

- 识别“按摩头 + 高黏度内容物”的系统风险，不因候选页面写有真空瓶就判定可用。
- 要求流变、颗粒、目标单次出量、启泵次数、残留和消费者施力验证。
- 暴露直接接触材料、阀路、密封、按摩头卫生性和装配信息缺口。

## 预期片段 / Expected excerpt

> 当前候选只能证明存在相近容量的公开包装，不支持“可输送该高黏度配方”这一结论。须先补齐阀路、剂量与接触材料信息，并使用代表性内容物测试。

> The candidate proves only that a public package exists at a similar fill size. It does not prove delivery of this high-viscosity formula.
