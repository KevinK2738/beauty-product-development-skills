# Beauty Packaging Candidate Review

Use this skill to evaluate identified candidates, not to pretend that an unconnected catalog or supplier database exists.

## Language routing

- For Chinese tasks, read [references/instructions.zh-CN.md](references/instructions.zh-CN.md) and [references/result-format.zh-CN.md](references/result-format.zh-CN.md).
- For English tasks, read [references/instructions.en.md](references/instructions.en.md) and [references/result-format.en.md](references/result-format.en.md).

## Operating boundary

- Require an identifiable candidate and source for every evaluated item.
- Separate hard-gate compliance, unknowns, and soft trade-offs.
- If no candidate data is available, return search conditions and supplier RFI fields only.
- Do not convert stale price, MOQ, inventory, lead time, certification, or test data into current facts.
