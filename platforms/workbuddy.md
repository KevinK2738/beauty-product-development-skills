# WorkBuddy 安装适配 / WorkBuddy installation

## 中文

WorkBuddy 官方文档说明可导入本地 Skill 包。导入时选择一个完整的 `skills/<skill-name>/` 目录或按客户端要求打包该目录，不要只上传 `SKILL.md`，否则双语指令、案例和模板会缺失。

官方入口：[Skills Market 功能说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)

逐个 Skill 测试三类固定场景：快速文本、专业文件、停止/降级。记录导入方式、客户端版本、模型、触发情况、产物及五维评分。只有完成 24 次真机运行并达到统一门槛后，才能在 `COMPATIBILITY.md` 标为通过。

## English

WorkBuddy's documentation describes importing local skill packages. Import one complete `skills/<skill-name>/` package as required by the client; do not upload only `SKILL.md`, because that would omit references, examples, and templates.

Run the three fixed scenarios for each skill and record client version, model, trigger behavior, artifacts, and scores. Compatibility may be published only after all 24 platform runs pass the shared gate.
